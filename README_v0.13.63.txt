Alpine Team Manager v0.13.63

変更点
- 1日1回、起動時に version.json から公開最新版を確認
- 新版がある場合のみ更新案内を表示
- 更新案内からバックアップ作成、アプリURLコピー、更新手順表示が可能
- 「今回はそのまま使用」で閉じても、旧版のままなら翌日の初回起動時に再表示
- バージョン確認通信に失敗した場合は成功扱いにせず、次回起動時に再試行
- v0.13.62までのHOME折りたたみ、所属選手登録、SAJ週次同期を維持

GitHub更新対象
- index.html
- app.js
- version.json（必須。今後の最新版通知の基準ファイル）

今後バージョンアップするたびに version.json の version も最新番号へ更新してください。
