Alpine Team Manager v0.13.60

変更内容
- 登録選手の全国ランクを端末 localStorage に保持
- 全国ランク未取得時は起動時に即時取得
- 取得済みの場合は、毎週木曜日を更新基準日として、それ以降の最初の起動時に1回だけ取得
- 木〜日曜に起動しなかった場合も、翌月曜以降の最初の起動で取得
- 取得失敗時は前回保存データを維持し、次回起動時に再試行
- 新規登録などでキャッシュに存在しないSAJ番号がある場合は即時取得
- Supporterデータ更新ファイルは同じ端末保存済み全国ランクを再利用
- Supporter更新ファイル作成時、週次更新が未完了なら更新を試してから出力
- 表示バージョン v0.13.60

GitHub Pages更新
既存リポジトリの index.html を本ファイルで置き換えてください。
他の画像・manifest・sw.js等は変更不要です。
